## [1.0.0] - 2024-XX-XX

### Added
- One-click FPS Unlock to 9999 FPS
- CPU Performance Optimization (process priority, thread scheduling, core affinity)
- GPU Performance Optimization (graphics quality, texture streaming, V-Sync control)
- RAM Optimization (working set, memory allocation, cache tuning)
- Windows Performance Optimization (power plan, visual effects, timer resolution, game mode)
- Automatic Configuration Backup before every modification
- Change Journal System with timestamped records of all changes
- Selective Restore per category (FPS, CPU, GPU, RAM, Windows)
- Full System Restore to revert all changes at once
- Configuration Validation for XML integrity checks
- Roblox Auto-Detection (installation path, config file, running status, version)
- Cybersigilism Holy Tuff Black Chrome UI Theme
- SHA-256 hash verification support
- Comprehensive logging with auto-rotation
