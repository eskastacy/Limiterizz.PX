# PROJECT DIRECTIVE — LIMITERIZZ.PX
## ROBLOX FPS UNLOCKER & HARD PERFORMANCE OPTIMIZER

### 1. PROJECT OBJECTIVE

Saya ingin mengembangkan aplikasi Windows berbasis executable (.exe) yang berfungsi sebagai Roblox FPS Unlocker sekaligus Hard Performance Optimizer.

**Official Project Name: Limiterizz.PX**

Tujuan utama aplikasi adalah membuka konfigurasi FPS limiter Roblox Player dari pengaturan default menjadi target 9999 FPS, sekaligus menyediakan berbagai optimisasi performa Roblox untuk meningkatkan efisiensi penggunaan CPU, GPU, RAM, dan sistem secara keseluruhan.

Aplikasi harus memiliki karakteristik:

- One-click operation.
- Compact and professional interface.
- Lightweight application.
- Fast execution.
- Reliable configuration management.
- Automatic Backup & Restore.
- Open-source distribution through GitHub.

Aplikasi bukan sekadar GUI untuk mengubah angka pada XML. Seluruh proses harus memiliki validasi, error handling, backup, dan mekanisme pemulihan.

**Primary Objective:**

Membangun Roblox FPS Unlocker dengan target konfigurasi 9999 FPS, dilengkapi modul optimisasi performa dan kemampuan mengembalikan seluruh konfigurasi ke kondisi sebelumnya.

### 2. ROBLOX FPS UNLOCKER — CORE FUNCTIONALITY

Target konfigurasi:

`%LOCALAPPDATA%\Roblox\GlobalBasicSettings_13.xml`

Contoh lokasi aktual:

`C:\Users\Administrator\AppData\Local\Roblox\GlobalBasicSettings_13.xml`

Jangan melakukan hardcode username Administrator. Gunakan environment variable `%LOCALAPPDATA%` agar aplikasi kompatibel dengan berbagai akun Windows.

#### FPS Configuration

Roblox secara default memiliki FPS cap 60 FPS, sedangkan pengaturan FPS yang tersedia melalui konfigurasi tertentu dapat mencapai 240 FPS.

Saya ingin Limiterizz.PX menyediakan target konfigurasi:

<badge color="success">TARGET FPS: 9999</badge>

Persyaratan implementasi:

1. Identifikasi parameter FPS limiter pada XML.
2. Analisis struktur XML sebelum melakukan perubahan.
3. Temukan key atau parameter yang benar-benar digunakan Roblox untuk mengatur FPS.
4. Ubah nilai konfigurasi FPS menjadi 9999 jika parameter tersebut mendukungnya.
5. Pertahankan seluruh konfigurasi XML lainnya.
6. Jangan menghapus atau merusak node yang tidak berkaitan.
7. Pastikan file XML tetap valid setelah dimodifikasi.
8. Lakukan verifikasi ulang setelah penyimpanan.
9. Berikan notifikasi apabila konfigurasi berhasil diterapkan.
10. Apabila struktur XML berubah setelah update Roblox, deteksi perubahan tersebut dan tangani secara aman.

Jangan mengasumsikan nama key atau struktur XML. Verifikasi berdasarkan file aktual dan perilaku Roblox.

#### One-Click FPS Unlock

Buat satu tombol utama:

**UNLOCK FPS — 9999**

Ketika ditekan:

- Deteksi instalasi Roblox.
- Identifikasi konfigurasi Roblox Player.
- Periksa apakah Roblox sedang berjalan.
- Buat backup konfigurasi awal.
- Terapkan perubahan FPS.
- Validasi hasil perubahan.
- Tampilkan status konfigurasi terbaru.

Status yang ditampilkan:

- FPS Configuration: Locked / Unlocked.
- Target FPS: 9999.
- Configuration Status: Valid / Invalid.
- Roblox Process: Running / Not Running.
- Backup Status: Available / Not Available.

Jangan menampilkan status Unlocked apabila perubahan sebenarnya gagal.

### 3. CONFIGURATION MANAGEMENT & AUTOMATIC BACKUP

Implementasikan sistem backup dan pengelolaan konfigurasi yang aman.

Fitur wajib:

- Automatic Backup.
- Original Configuration Protection.
- Configuration Snapshot.
- Backup History.
- Reapply FPS Unlock.
- Configuration Validation.
- Restore Original Configuration.

Ketentuan:

1. Simpan konfigurasi original sebelum modifikasi pertama.
2. Jangan menimpa backup original dengan konfigurasi yang sudah dimodifikasi.
3. Simpan snapshot sebelum setiap perubahan yang dilakukan aplikasi.
4. Catat nilai sebelum dan sesudah perubahan.
5. Simpan riwayat perubahan secara persisten.
6. Pastikan backup tetap tersedia setelah aplikasi ditutup.
7. Jangan menghapus backup original setelah proses restore.
8. Jika XML corrupt, jangan menimpa file asli.
9. Gunakan atomic file replacement jika memungkinkan.
10. Pastikan pengguna dapat mengetahui konfigurasi mana yang telah dimodifikasi.

Gunakan sistem **Change Journal** untuk mencatat seluruh perubahan.

Contoh informasi yang disimpan:

- Modification ID.
- Modification Timestamp.
- Configuration Category.
- Original Value.
- Modified Value.
- Modification Status.
- Restore Status.

Jangan menganggap nilai default Windows selalu sama untuk semua perangkat. Simpan nilai aktual sebelum perubahan dilakukan.

### 4. FULL RESTORE & REVERT SYSTEM

Implementasikan fitur utama:

**RESTORE TO DEFAULT**

Fitur ini memungkinkan pengguna mengembalikan seluruh konfigurasi Roblox dan optimisasi Windows yang dimodifikasi Limiterizz.PX ke kondisi sebelum aplikasi melakukan perubahan.

#### A. Complete Restore

Sediakan tombol:

**RESTORE ORIGINAL STATE**

Ketika dijalankan:

1. Identifikasi seluruh perubahan yang dilakukan Limiterizz.PX.
2. Periksa ketersediaan backup original.
3. Kembalikan `GlobalBasicSettings_13.xml` ke kondisi sebelum FPS Unlock diterapkan.
4. Kembalikan pengaturan Windows yang dimodifikasi aplikasi ke nilai awal.
5. Kembalikan konfigurasi CPU, GPU, dan power management apabila sebelumnya diubah.
6. Hapus konfigurasi sementara yang dibuat aplikasi jika sudah tidak diperlukan.
7. Lakukan verifikasi terhadap setiap proses restore.
8. Tampilkan laporan hasil pemulihan.

#### B. Selective Restore

Sediakan opsi pemulihan terpisah:

- Restore FPS Configuration.
- Restore CPU Optimization.
- Restore GPU Optimization.
- Restore RAM Optimization.
- Restore Windows Optimization.
- Restore All Settings.

Pengguna harus dapat mengembalikan satu kategori tanpa harus membatalkan seluruh optimisasi.

#### C. Restore Everything

Sediakan tombol:

**RESTORE EVERYTHING**

Fungsi ini mengembalikan seluruh perubahan yang dilakukan Limiterizz.PX berdasarkan change journal dan backup yang tersedia.

Jangan mengubah pengaturan yang tidak pernah dimodifikasi oleh aplikasi.

#### D. Restore Verification

Setelah proses pemulihan:

- Bandingkan konfigurasi hasil restore dengan snapshot original.
- Validasi struktur XML.
- Verifikasi nilai konfigurasi Windows yang dipulihkan.
- Identifikasi pengaturan yang gagal dikembalikan.
- Tampilkan status setiap komponen.

Gunakan status:

- Successfully Restored.
- Partially Restored.
- Restore Failed.
- Original State Verified.

Jangan menampilkan status berhasil apabila masih terdapat perubahan yang belum dikembalikan.

#### E. Restore Safety Mechanism

Sebelum Full Restore:

1. Tampilkan konfirmasi kepada pengguna.
2. Berikan informasi perubahan yang akan dibatalkan.
3. Jangan menghapus backup original.
4. Pastikan proses restore dapat dilanjutkan jika terjadi kegagalan.
5. Deteksi perubahan manual yang dilakukan pengguna setelah snapshot dibuat.
6. Berikan peringatan sebelum menimpa perubahan manual tersebut.

Jika nilai konfigurasi sudah diubah secara manual setelah optimisasi, jangan langsung menimpanya tanpa konfirmasi.

#### F. Restore Interface

Tambahkan bagian khusus:

**SYSTEM RESTORE**

Tampilkan:

- Current FPS Configuration.
- Original FPS Configuration.
- Applied Optimizations.
- Available Backup.
- Last Modification.
- Restore Status.

Sediakan dua pilihan:

**RESTORE SELECTED** — Mengembalikan kategori konfigurasi yang dipilih.

**RESTORE EVERYTHING** — Mengembalikan seluruh perubahan yang dilakukan Limiterizz.PX.

### 5. ROBLOX HARD PERFORMANCE OPTIMIZATION

Tambahkan modul khusus:

**HARD PERFORMANCE OPTIMIZATION**

Tujuannya mengoptimalkan Roblox Player untuk mendapatkan performa dan frame consistency yang lebih baik.

Optimisasi harus terukur dan tidak menggunakan tweak yang hanya terlihat ekstrem tanpa memberikan peningkatan nyata.

#### A. CPU Optimization

- Optimalkan process priority Roblox sesuai kebutuhan.
- Hindari penggunaan priority Realtime.
- Evaluasi CPU scheduling.
- Minimalkan background process yang tidak diperlukan.
- Hindari CPU affinity restriction yang membatasi performa.
- Evaluasi penggunaan thread dan CPU utilization.
- Hindari konfigurasi yang meningkatkan CPU overhead.

#### B. GPU Optimization

- Optimalkan pemilihan GPU pada sistem multi-GPU.
- Pastikan Roblox menggunakan GPU performa tinggi jika tersedia.
- Evaluasi GPU scheduling.
- Hindari memaksakan driver-level settings yang tidak kompatibel.
- Optimalkan penggunaan GPU sesuai kemampuan hardware.
- Jangan mengubah konfigurasi driver secara agresif tanpa alasan teknis.

#### C. RAM Optimization

- Minimalkan memory overhead.
- Hindari penggunaan RAM yang tidak diperlukan.
- Evaluasi memory pressure ketika Roblox berjalan.
- Hindari RAM cleaner yang melakukan working-set trimming berulang.
- Jangan melakukan standby-list cleaning secara terus-menerus.
- Hindari memaksa pengosongan RAM yang menyebabkan aplikasi melakukan reload data.

#### D. Windows Performance Optimization

Evaluasi optimisasi:

- Power Plan.
- Game Mode.
- Background Application Overhead.
- Unnecessary Startup Applications.
- Power Throttling.
- Hardware-Accelerated GPU Scheduling.
- Windows Graphics Preferences.

Setiap optimisasi harus memiliki:

- Penjelasan fungsi.
- Status awal.
- Status setelah perubahan.
- Dampak yang diharapkan.
- Opsi restore.

Jangan menonaktifkan Windows Defender, Windows Update, firewall, atau komponen keamanan sistem demi mengejar FPS.

#### E. Roblox Runtime Optimization

Prioritaskan:

- Frame pacing.
- Frame consistency.
- CPU bottleneck reduction.
- GPU utilization.
- Input responsiveness.
- Background overhead.
- Stability during long gaming sessions.

Jangan menggunakan modifikasi binary Roblox, bypass keamanan, atau manipulasi anti-cheat.

Seluruh optimisasi harus reversible melalui System Restore.
